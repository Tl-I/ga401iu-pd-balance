# GA401IU PD Balance

ASUS ROG Zephyrus G14 GA401IU에서 USB-C PD 사용 중 배터리 전류를 0mA 부근으로
유지하는 Windows용 실험 프로그램입니다. 검증한 펌웨어는 BIOS 222입니다.
소프트웨어 피드백 제어이며 물리적인 배터리 분리나 하드웨어 Pass-Through 모드를
구현한 것은 아닙니다. 다른 모델에 맞춰 모델 검사를 우회해서 실행하지 마세요.

## 동작

- 기존 ASUS 충전 목표에 맞춰, 목표보다 0.5%p 낮은 실제 잔량에서 HOLD에 진입합니다.
- 배터리 전류를 약 2초 간격으로 읽고 ISL9238B의 충전 전류 설정(register 0x14)만 조절합니다.
- 값이 그대로여도 약 60초마다 저널 저장·검증·쓰기·재조회를 거쳐 갱신합니다.
- 전압/FET/전력 제한/EC 펌웨어를 변경하지 않습니다. 기존 충전 목표를 설정하는 앱도 아닙니다.
- PD 분리 후에는 전원 이벤트를 기다리고, 통신 장애는 2초 간격으로 복구를 시도합니다.
- 정상 정지는 실제 충전기 레지스터를 다시 읽어 EC의 현재 요청으로 복원을 확인합니다.

## 요구 사항

- GA401IU 및 검증한 BIOS 222, 배터리 정상 동작, USB-C PD 20V / 2.8A 이상
- Windows x64, PowerShell 7, 관리자 권한
- 소스 빌드: Visual Studio Build Tools(C++ 및 C#), Windows SDK, .NET 8 런타임

이 프로그램은 서명된 InpOutx64 드라이버로 포트 I/O를 수행합니다. 드라이버가 Windows
정책에 의해 차단되면 중단합니다. TESTSIGNING이나 보안 기능 해제를 설치 절차에 포함하지 않습니다.
드라이버는 관리자 권한의 광범위한 포트 접근을 허용하므로 사용 전 소스를 검토하세요.

## 빌드와 시험

```powershell
pwsh -NoProfile -File .\Build.ps1
pwsh -NoProfile -File .\Test.ps1
```

두 명령은 드라이버를 로드하지 않습니다. 시험은 모의 전송으로 임계값, 전원 분리,
타이머 갱신, 갱신 실패, 복구, 저널 및 정상 해제를 확인합니다.

## 사용

기존 사본이 동작 중이면 원래 사본에서 정상 정지하고 종료를 확인한 뒤 새 사본을 사용하세요.
아래 명령은 관리자 PowerShell 7에서 실행합니다.

```powershell
# 캐시만 확인: 충전기 쓰기/SMBus 명령 없음
.\Test-SignedIo.ps1

# 자동 제어 시작. 원래 창에서 로그를 확인할 수 있습니다.
.\Start-PdAtLogon.ps1

# 다른 관리자 PowerShell에서 정상 정지
.\Stop-PdSystemPower.ps1

# 기존 충전 목표를 유지하며 EC 충전으로 돌아가기
.\Resume-NormalCharging.ps1
```

로그는 `logs/`에 저장됩니다. 자동 시작을 원하면 관리자 PowerShell 7에서
`Install-PdAutostart.ps1`을 실행합니다. `GA401 PD Battery Balance` 로그인 작업을
등록하며 즉시 실행하지 않습니다. 제거할 때에는 먼저 정상 정지를 확인한 뒤 이
예약 작업을 제거하세요. 현재 사용자에게 등록되는 15초 지연 로그인 작업입니다.

## 복구 기록

`ga401signed.exe.pending`는 쓰기 전 저장하는 두 슬롯의 저널입니다. 실행 중 파일을
지우지 마세요. 비정상 종료 후에는 시작 스크립트가 실제 전류와 저널 소유값을
확인한 뒤 복구합니다. 알 수 없는 값이나 손상된 기록을 임의로 덮어쓰지 않습니다.
저널은 하드웨어 자동 롤백 장치가 아니며, 전원 차단 후의 무조건 복원을 보장하지 않습니다.

## 검증 범위와 알려진 한계

- GA401IU 한 대의 BIOS 222에서 관찰한 결과입니다. 다른 보드·BIOS는 검증하지 않았습니다.
- 2026-10-25 수정 후 7분의 연속 관찰에서 초기 진입 후 208표본이 모두 0mA였고
  6회 동일 값 갱신의 실제 재조회가 통과했습니다. 장기간·모든 부하에서의 보장은 아닙니다.
- 진입·부하 변화·EC 개입·통신 복구 중에는 배터리 충방전이 발생할 수 있습니다.
- 전원 이벤트가 없는 충전기 종류 변경은 다음 이벤트까지 감지가 지연될 수 있습니다.
- 이 기기에서는 Windows AC 표시와 검증한 충전기 종류가 일시적으로 어긋난 기록이
  있습니다. 전원 종류 판정 실패 시 임의로 배터리 상태로 간주하지 않습니다.
- 개인 UXTU/GHelper 수정본과 프리셋 라우팅은 포함하지 않습니다.
  `Start-ChargingIndicator.ps1`은 검증된 연결 변화에 PowerRibbon을 실행하며, 정상 상태에서는 이벤트만 기다립니다.
